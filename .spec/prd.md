# PRD — 精简截图翻译 MVP

## 1. 产品定位
比有道轻10倍的桌面截图翻译。专注3件事：截图、OCR、保存。不做划词、文档、语音。

## 2. 用户与场景
- 用户：开发者/学生/运营，看英文/韩文资料需快速译中
- 场景：阅读外文PDF/网页/游戏 -> 按热键框选 -> 悬浮卡片看译文 -> 一键保存

## 3. 功能列表 + 验收标准 (AI 的完成尺子)

### F1 全局截图 (P0)
- **描述**: 全局热键 `Ctrl+Shift+A` (可配置) 触发，冻结当前屏幕显示半透明遮罩，鼠标拖拽框选区域
- **验收**:
  - [ ] 未选中时按 ESC 取消，有选中时双击或回车确认
  - [ ] 支持多显示器、125%/150% 缩放不偏移
  - [ ] 框选后自动进入 F2+F3，耗时 <150ms
  - [ ] 交互：显示选区宽高、放大镜、ESC/Enter 响应

### F2 本地 OCR (P0)
- **描述**: 对框选图片做本地OCR，支持 `zh / en / ko`，自动检测语言，无网络可用
- **验收**:
  - [ ] 印刷体中英韩准确率 >95% (测试集 100张)
  - [ ] 单张耗时 <800ms (1080p选区, i5平均)
  - [ ] 接口 `IOcrService.recognize(imageBuffer) -> {text, lang, confidence}`
  - [ ] 失败时返回 errorCode (NO_TEXT / LOW_CONFIDENCE)，不崩溃

### F3 混合翻译 (P0)
- **描述**: 将OCR文本译至目标语言(默认自动中英韩互译)，采用混合路由
- **路由逻辑**:
  ```
  用户框选 -> OCR -> 语言检测 -> 目标语言推断(中->英, 英->中, 韩->中)
  -> 快通道 DeepL (若配置)  50-150ms 出结果先渲染
  -> 并行 精通道 opencode LLM (Gemini 2.5 Flash / Claude) 800-1200ms 后若质量更高则替换
  -> 熔断: DeepL无Key或失败则直走 LLM; 均失败显示错误
  ```
- **验收**:
  - [ ] 中英韩互译均可用，自动检测源语言准确率 >90%
  - [ ] 快通道<200ms感知，精通道替换时有淡入动画不闪烁
  - [ ] 支持术语表(可选): 如 `opencode` 不翻译
  - [ ] 接口 `ITranslateRouter.translate({text, from, to}) -> {fast, refined?}`

### F4 悬浮翻译卡片 (P0)
- **描述**: 紧贴选区显示可拖拽卡片，展示 原文/译文/操作栏
- **验收**:
  - [ ] 显示原文+译文对照，支持一键复制原文/译文
  - [ ] 操作栏: `复制译文` `重新OCR` `保存` `固定/关闭`
  - [ ] 可拖拽、边缘自适应不超出屏幕、透明度/置顶可配置
  - [ ] 切换语言(下拉)即时重译

### F5 保存截图 (P0)
- **描述**: 保存原图+可选译文叠加图到本地，记录历史
- **验收**:
  - [ ] 默认路径 `~/Pictures/TransShot/`, 可在设置改
  - [ ] 文件名 `TransShot_{YYYYMMDD_HHmmss}_{lang}.png`
  - [ ] 保存后 Toast 提示+打开文件夹按钮

### F6 设置与系统 (P1)
- **描述**: 托盘常驻、开机自启、热键/语言/路径/ API Key 配置
- **验收**:
  - [ ] 托盘菜单: 截图/设置/退出
  - [ ] 设置页: 热键录制、目标语言、保存路径、DeepL Key、opencode 模型选择
  - [ ] 配置持久化 `electron-store`, 含 `.env.example`

## 4. 非功能需求
- 包体 <80MB (Electron), 内存待机 <150MB
- 离线可用：截图+OCR 无网可用，翻译无网时提示但不崩
- 安全：API Key 仅存本地，不上传
- 日志：`logs/app.log` 可追踪

## 5. 非目标 (NOT GOAL)
- 不做划词翻译、不做整页PDF翻译、不做语音输入
- MVP 不做云同步、不做账号体系

## 6. 里程碑
- M1: 截图+悬浮卡片空壳可跑
- M2: OCR 本地可跑
- M3: 翻译双通道可跑
- M4: 保存+设置+打包
